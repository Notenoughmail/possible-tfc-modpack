# Electronics Crafting Table

<BlockImage id="thoriumreactors:thorium_crafting_table" sacle="8" />

Certain electronic components, while being able to be hand built,  require a certain degree of precision not capable with just a regular crafting table. Thus the <ItemLink id="thoriumreactors:thorium_crafting_table" />, a semi-electronic table that passively assists you in creating electronic components.

It also has a greater area to work in, though it is picky about the placement of materials.

# Automation

Unfortunately the <ItemLink id="thoriumreactors:thorium_crafting_table" /> cannot be automated, but there is another machine which performs the same task which can (often for cheaper as well). This machine is the <ItemLink id="jumbofurnace:jumbo_furnace" /> a hulking 3x3x3 device.
